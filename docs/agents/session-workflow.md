# Session workflow

Start at [AGENTS.md](../../AGENTS.md) and select a row of the
[change map](../reference/change-map.md). Read STATE when resuming work or using
shared compute; inspect live state before acting on a resource claim.

Keep detailed working notes with the active plan. At milestones record the concrete
change, validation and next action. STATE links to details instead of accumulating
session transcripts. Preserve completed plans with their original evidence.

A handoff names the branch/commit, changed behavior, checks actually run, remaining
uncertainty and next action. Durable rules and evidence belong in versioned files
reachable from the map, independent of an agent's private memory.

Use bounded searches and relevant file sections. Delegate when useful and authorized;
include evidence paths with findings and inspect them when a decision depends on them.
