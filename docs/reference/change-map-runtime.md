## Current limitations

Each stage is a flat bash script under `scripts/` whose whole body is one `exec` into a `locomani.pipeline.run_*` module, run by hand or by `run_overnight.sh` (the only script that calls other scripts); the composed CLI, the stage modules and the launcher are gone. The crate script runs its expert directly (`tasks/crate/prepare.py`, expert kind from `task.expert`). The two evaluators own their stacks through `pipeline/stack.py`, which is why that seam remains. ScaleBFM has an independent in-process runner. The streamed-pose experts require a deploy built with the hand-ownership patch (`SONIC_DEPLOY_ROOT` selects it). SONIC consumers
still read derived compatibility properties of ReachConfig; five historical strategy
switches migrate only at the version-1 JSON boundary. GymRuntime and VlaConfig carry production runtime choices explicitly. Legacy
RTC diagnostics retain scoped instrumentation hooks. The gym-options report covers
its parser; child receipts and delivery tests cover subprocess settings.
