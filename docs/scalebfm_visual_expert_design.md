# ScaleBFM 面向视觉 VLA 的抓瓶专家设计草案

日期：2026-09-08。目标：看见瓶子后走近，接近时逐渐抬手，能舒适够到就抓，需要时适量弯腰，生成 VLA 可模仿的连续轨迹。本文为设计建议，未修改控制或启动采集。

已确认的输入边界：用户选择双 RGB 相机 + 本体状态，VLA 不读取物体真值。专家可用仿真信息辅助生成与审计，但任务决策必须符合部署观测可支持的信息条件。机器人低层的状态反馈与 VLA 的输入是两个不同边界。

## 核心约束

在相近的部署观测历史与任务条件下，专家应给出相容的动作。动作变化应有观测中的原因；不能靠学生无法获得的计时器、随机站距、接触真值、遮挡后的实时物体真值决定分支。

允许视觉估计误差、短期记忆和连续运动生成器；关键是专家与学生/共享执行器具备相同的信息条件。不是要求完全无状态。Action chunk 预测未来动作，不等于模型自动拥有过去图像或动作的记忆。

## 建议的数据流

1. 当前相机观测 + 本体状态 + 可用历史 → 可观测场景估计。
2. 场景估计 → 连续的接近/伸手/姿态选择/夹爪策略。
3. 策略 → 有明确坐标与时间语义的动作。
4. 收集和部署共用的参考生成器 → ScaleBFM 未来六帧 → 关节控制。

仿真真值单独供审计和筛选使用。决策函数不直接接收 MuJoCo sim 对象，而接收一个受限观测结构，便于检查是否越过信息边界。这里仅定义设计边界，不强制某种模块/API 实现。

## Privileged 信息的用法

| 信息 | 建议用途 | 不应支持的行为 |
|---|---|---|
| 瓶子、桌面真值几何 | 第一版作为可视场景估计的替代，限制可见性、更新率、精度；生成监督和离线评价 | 瓶子被完全遮挡后仍精确追踪其新位姿 |
| 机器人关节、IMU、FK | 在图像+本体输入方案中用于控制、可达性和动作坐标转换 | 若学生看不到相关状态，却据其隐含变化切换任务行为 |
| 分割、深度、遮挡真值 | 计算可见性及审计；构造与 RGB 所含证据一致的初始代理观测 | 把真值姿态当作“只要可见就必然能精确推断”的保证 |
| 接触/附着/成功标志、未来物体轨迹 | 离线判定质量、失败原因 | 依赖隐形接触开关立即抬起；提前知道未来扰动 |
| 相机标定、机器人几何和自碰撞模型 | 固定的执行器知识、FK 和可达性预计算 | 根据当前看不到的环境几何在部署共享执行器中偷偷修正动作 |

首版可用真值代理节省感知工程，但最终需要 RGB 感知或学生闭环验证。加入噪声本身不能证明可学习性。

## 连续动作逻辑

| 可用证据 | 动作趋势 | 分支要求 |
|---|---|---|
| 瓶子方向明确、离桌较远 | 走向可接近区域；身体朝向同时兼顾视野与右手操作 | 不把身体 yaw、手掌方向和相机视线强制设成同一个角度 |
| 已接近可达区域、瓶子位置置信度足够 | 随剩余接近距离连续抬手，逐渐减速 | 抬手由实测接近程度驱动；不按出生后固定第几秒启动 |
| 手臂在舒适范围内可达且路径无明显阻挡 | 直接对准、进入夹爪 | 不为增加动作花样强制弯腰 |
| 手臂舒适范围不足，桌沿限制继续向前 | 逐渐增加矢状面前倾/髋屈曲，必要时轻微屈膝 | 以可达性余量为依据；不能把一时跟踪误差当作够不到 |
| 瓶子与夹爪对齐且相对运动小 | 减速、合爪 | 接近/对齐条件用容差带和滞回，不依赖毫米级硬切换 |
| 夹爪已执行闭合 | 先小幅试提，观察瓶子是否随手移动 | 不使用 attached 真值决定抬起；失败可重新对准 |
| 瓶子已稳定随手抬离桌面 | 适量收回到舒适持物位置 | 持物和退手目标同样连续，不能在 phase 边界重置姿态 |

这些是解释和日志阶段，走路、抬手、减速、前倾可以重叠。相位标签不得作为学生没有的秘密输入。

## 运动生成：可观察进度决定目标，时间用于实现平滑速度

保留 min-jerk/Slerp、速度和加速度限制，但任务推进由实测身体/手相对目标的进度决定。按剩余误差和接近速度构造每次滚动的短期未来参考，ScaleBFM 仍需看到带方向和速度的未来帧。

不要恢复旧 clockless v4 的静态吸引点死区：尚未到达可达区域时，参考要表达继续走的意图。也不要为了消除死区在已对准或看不清时强制维持非零速度。路径进度、命令跟踪误差和任务条件共同确定何时推进、减速或恢复。

完整腕部命令必须连续，包括位置、旋转、偏置与反馈接入。插值从上一条实际命令衔接，并处理命令与实测状态的偏差；仅让 pad 几何路径平滑不够。本项目已证实腕旋转突变可诱发明显腰部侧弯，见 `scalebfm_sidelean_diagnosis_20260908.md`。

## 可达性与人体风格

先标定本机器人在不同前倾、轻微屈膝、肩肘姿态下的舒适可达范围，保留远离关节极限的余量。不是简单用肩到瓶子的球形距离。

用一致的姿态偏好：优先手臂、允许必要前倾、抑制不必要侧弯和扭腰、兼顾平衡与视野。同样场景采用同样偏好；让姿态多样性由瓶子深度/桌高等可见变化产生，而非不可见的随机风格参数。

初版继续使用 mode 2 验证连续参考与输入约束是否足够。若必要前倾无法实现或姿态持续不可接受，再独立验证 mode 6 的肩肘参考方案。mode 6 不直接控制 torso；mode 7 包含 torso 但也启用腿等其它 body，需要完整一致参考。不能先承诺某个模式会产生人类风格。

若扩大控制目标，记录动作空间与部署执行器必须同步，不能采集用有躯干约束的专家、部署退回无约束的 mode 2。

## 视觉与历史

现有 `configs/gr00t_bfm_vel4_2cam.py` 的 video/state 均为 delta_indices=[0]，只有当前帧；没有显式图像历史、前一动作或关节速度输入。

需要辨别接近速度、合爪前后、瓶子是否随手移动时，建议增加有限的图像/状态历史与先前实际执行动作，并明确地接入模型。历史长度先按视觉延迟与动作阶段实测确定。若维持当前单帧结构，专家就应限制隐藏相位和复杂遮挡恢复，不能声称学生拥有动作记忆。

头相机固定在 torso_link，没有独立眼球/颈部控制。应将目标改写为：走近时头相机持续给出足够目标证据；近距离允许腕相机接管精细对准，两视角有可用的交叠。评价真实瓶子可见像素、图像边界距离、手与瓶子的相对关系，而不只用“去掉机器人后的可见比例”。

短时自然遮挡可用学生同样可获得的历史维持估计，置信度下降；失去足够证据时减速、停进刀或调整视角，不能一直调用实时真值继续精确抓取。桌高/瓶深与相机安装导致两路都无法支持操作时，要修相机或动作范围。

## 收集与部署必须一致

- 现有采集 expert 每 20 ms 读取实时真值更新目标；eval 默认每 0.4 s 重规划并带延迟。任务层反馈条件不一致。
- 设计时将专家的场景估计更新与部署观测/重规划频率、延迟对齐；高频本体稳定反馈保留在双方共享低层。
- 明确每个 action 的参考坐标系、采样间隔、速度和未来帧语义。共享执行器不得在学生部署时使用物体真值修正预测。
- 若动作记录在公共执行器之前，就记录其输入；若记录之后就避免部署再次应用同样修正。最终传给 ScaleBFM 的目标另外记作审计 trace。
- 在同一初始状态测试已记录动作通过部署执行器的重放一致性，先排除动作表示损失；不能只看 open-loop action MAE。
- 任务层可预测一个短 action chunk，但每次只执行一段后重新观察；近抓取阶段的反馈频率应根据实际延迟和所需精度验证。

ACT 使用动作序列和 temporal ensembling 改善模仿执行，但它不能替专家修复观测中缺失的分支信息：[原论文](https://www.roboticsproceedings.org/rss19/p016.pdf)。

## 数据覆盖与验收

先固定一个右手抓瓶风格。用可见几何变化自然形成三类场景：直立可达、适量前倾可达、需要小步重新接近或对准。第一轮用少量有代表性的场景验证动作和可学习性，再扩大到 200+ 集。

保留自然的小偏差和成功恢复；剔除目标突变、严重侧倾/扭腰、长期看不见却精准操作、明显震荡和数值异常。身体指标应允许任务必要的前倾，不以“所有姿态都接近零”为目标。

增加部署容易遇到的恢复状态：停早、手尚未抬起、伸手偏一点、短时丢目标。专家需要能从这些状态继续完成，不能只录恰好沿时间轨迹到达的状态。

第一轮行为克隆后，在学生实际访问的状态上调用同样受限的专家补示范。DAgger 针对的正是动作改变后续观测分布的问题；其理论并不自动保证受限视觉学生能复制全知专家：[原论文](https://proceedings.mlr.press/v15/ross11a.html)。

关键验收：

1. 姿态与可视性：接近/抬手重叠、旋转/位置连续、必要前倾、侧倾/扭腰峰值及持续时间、关键阶段视觉证据。
2. 因果一致性：延迟接近会相应延迟抬手；可见地移动瓶子会改变手目标；完全遮挡后不会神奇追踪新的物体位置。
3. 恢复性：停早后仍会继续走；有小误差会重新对准；闭合后试提确认而非依赖附着真值。
4. 学生验证：已记录动作重放、小数据闭环、持出几何和固定种子评估。专家成功率、视频自然度和 open-loop MAE 都不能单独证明可学习。
