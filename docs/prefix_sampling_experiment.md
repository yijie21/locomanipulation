# 动作切换进入执行前缀的对照

目标是检验边界采样能否让模型及时预测下蹲。默认执行器的重规划周期、动作窗口、RTC、commit 和控制参数保持不变；实验结果不能用训练 loss 代替闭环成功率。

## 固定条件

- 起点：`outputs/train/cover400_tok/checkpoint-10000`。
- 数据：`datasets/g1_locomani_cover400_train`，380 条；不包含 val 或历史失败观测。
- 两组各 300 步，学习率 2e-5，有效 batch 64，同一数据/训练种子及 checkpoint 归一化。
- 普通组每个有效起点出现 1 次；边界组仅将选中的起点重复 4 次。每次仍从原始同一行读取观测，以及后续完整 40 帧标签。
- 阶段锚点：首次 planner mode=4、随后平均膝角相对指令开始时增加 0.25 rad、首次闭手。膝角事件只是身体响应代理，不能称为实际下降 6 cm；本次没有可靠的伸手起点标签，因此不伪造该事件。
- 对每个事件 e，额外采样起点 e-9..e，使事件落在 0..9；剪去越过 episode 末端、无法提供完整 40 帧的起点。重叠起点去重。其他走近/伸手/持物窗口全部保留。

`prefix_sampling.py` 产生带 parquet SHA-256 的离线清单；训练启动校验数据身份与指纹，在当前进程的 GR00T factory 安装可选数据集类。它改变 shard 中的起点重复次数并同步 shard 长度，不修改第三方源码或数据文件。使用现有 fork worker 配置。

## 执行归属

`diag_transition_live.py` 的捕获模式给每次推理分配 chunk ID。默认 async、ensemble=1 路径在采用窗口时同时保存该 ID；发送时记录 ID、真实选取的 action_index、观测时间、手指延迟参数。记录的 token/手指仍是实际发送值。

诊断字段 `trace_source` 只留在 Python 捕获日志，不改变协议包。初始化混合、同步及 lockstep 路径没有本次新增的完整归属；ensemble 明确标注为混合而非随意归属于某一窗口。手指若启用延迟，不能把其执行值直接归因于当前 token 的索引。

WBC 当前未回传输入 ID。因此 `audit_prefix_execution.py` 将发送归属与 WBC 中的 token 内容证据分开：精确核对 ID/index 对应的预测 token；接收侧只报告 0.5 秒内唯一或重复 payload 候选。重复、不匹配以及丢帧都不能当作确认接收。没有为此修改底层控制器。

## 诊断与停止条件

训练完成后，`probe_prefix_models.py` 对原 checkpoint、普通续训、边界续训使用相同历史观测和相同逐请求随机种子，采用默认客户端同样的 FSQ snap。固定抽取 30 个未倒瓶的桌前停住观测和 20 个走近观测。解码器必须先通过真实 WBC 下一步命令校准。

报告前 10 帧及全部 40 帧中的下蹲趋势、前缀闭手次数，同时保留逐请求结果。固定历史下的解码只是动作趋势代理，不是身体 rollout。走近状态上的下蹲增加需要单独检查，不能只看桌前指标。历史失败观测只用于诊断，不参与梯度训练；这些相关观测不能当作 50 个独立闭环试验。

若边界组没有相对普通续训带来明确的前缀改善，本轮不能宣称修复或启用其为默认模型。不自动增加训练步数、改采样倍率或改控制参数。若有改善，仍需独立闭环确认发送、身体响应、倒瓶及完整成功率。

运行记录、命令、训练日志、采样清单与诊断结果集中在 `outputs/diag/prefix_experiment_20260906/`。本次开始时中止过一次导入参考副本的训练，保留在 `.aborted_import` 文件/目录中，不纳入两组对照；正式启动器明确从 `src/gr00t` 导入。

本轮已执行完毕：三种模型的桌前前缀下蹲趋势均为 0/30，未达到目标，不启用新模型。完整结果见 [实验报告](../outputs/diag/prefix_experiment_20260906/REPORT.md)。

指标更正：后续专家阳性对照表明，0.25 rad 的前缀膝角阈值不适合单独判定下蹲启动。旧 0/30 不能单独证明采样无效；应结合连续幅度与真实身体下降。复核记录在 `outputs/diag/prefix_target_audit_20260906/`。
