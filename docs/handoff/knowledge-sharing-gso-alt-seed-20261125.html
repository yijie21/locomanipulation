The 9 entries in the library

Single-grasp (7)

  • The approach path passes through a neighbouring free object
  • Long box: grasp it from the end instead
  • Lift to the goal height and hold until the judging window ends
  • A near-square box slips when the jaw closes along its diagonal
  • The arms knock over tall objects while walking
  • Every side approach path is blocked
  • Not enough grip force on a thin rod

Bimanual-lift (2)

  • Lift to the goal height and hold until the judging window ends
  • While walking in before the hug, the fingers knock over objects at the platform edge

How knowledge is shared within one task category

  • Joint diagnosis of failures. The Reviewer puts the failed rounds of every object into one evidence table, one row per round, and diagnoses them together.
  • Scene-graph evidence across objects. The Reviewer analyzes the PAST scene-graph records of all objects: what each step was expected to do, compared with what actually happened.
  • One code structure for all objects. Object names are never hard-coded. A flow made for one kind of object is chosen by its features (size, height, mass, …), so a similar object reuses it.
  • Accept only net wins. A code change is kept only if it wins clearly more starts than it loses, across all objects (gains − losses ≥ 3 and losses ≤ gains / 3).
