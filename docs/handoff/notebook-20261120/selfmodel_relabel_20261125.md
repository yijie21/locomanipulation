# selfmodel_relabel_20261125：把轨迹中间点当作新起点、标签仍用最终落点，能不能代替真实的"停稳后慢速进入"数据

- **日期**：2026-11-25。在任何训练之前写好，单独提交。
- **机器**：4090，在 1–3 号卡里挑空的用。
  - 必须在 [selfmodel_train3_20261125](selfmodel_train3_20261125.md) 开训（约 13:00Z）之前跑完。来不及就让出卡。
  - 4090 的 CPU 正在被采集占满，所以训练只开 4 个 CPU 线程。
- **代码**：`selfwm`。
  - 训练：`reachwm_20261030/train.py E3_ensemble`，配方原样：3 万步，batch 1024，5 个成员，seed 0。
  - 环境变量：`REACHWM_GOAL_REF=1`，和 `models_goalref_wrist_odo` 一样。
  - 中间点样本：用一个新脚本生成，存成和原数据同样布局的 npz。`data.py` 和 `train.py` 一行不改。
- **数据**：ScaleBFM 在我们自己仿真里的旧数据，`loco_outputs/simple_selfmodel_20261119/` 下的 `data_graspr_odo` 和 `data_graspr_wrist_odo`。
  - 每次重置走完以后伸三下：开点、预抓取（抓取点后方 10 cm）、慢速进入（0.08 m/s，参考从中点开始）。
  - 划分沿用 `data.py`，按重置编号分，三个模型用同一份划分。
- **用户的提议（2026-11-25）**：一次伸手录下了整条手的轨迹，把轨迹上的不同位置都当作起点，输出都用最后的落点，这样也许不用专门补采短伸手。用户决定先测这个办法，同时照常补采（[selfmodel_data3b_20261125](selfmodel_data3b_20261125.md)）。

## 假设

我的看法是这个办法替代不了真实数据。理由有三条：
1. **中间点上手在动，不是停稳的。** 模型读出发前三帧，看得出速度。从静止起步的那一下（加速、重力下垂、小幅度时停不准）不在这些样本里。
2. **控制器在中间点正跟着一条早已发出的参考**，参考比身体超前，ScaleBFM 超前 0.16 s。真在那里重新发命令，参考会从当前点重新规划，速度和时长都不同。
3. **速度和距离不一样。** 中间点剩下的路程是 0.15 m/s 长伸手的尾巴；抓取时是从停稳状态以 0.08 m/s 伸 5–12 cm。

不过这些样本毕竟是真实发生过的，能教会模型"手在这附近时控制器的偏差往哪边"。所以我预计它比完全没有短伸手要好，但比不上真实的慢速进入。

## 三个模型（只有训练集不同，验证和评估完全相同）

- **C（对照）**：只用开点和预抓取两种伸手，不用进入段，也不加中间点。
- **A（用户的办法）**：C 的数据，再加上从这些伸手里切出的中间点样本。
  - 每一段从命令后 0.3 s 开始，每隔 0.2 s 取一个新起点，取到离结束 0.3 s 为止。
  - 新起点的前三帧就是那一时刻的真实状态。
  - 命令仍是原来的目标和手腕朝向，换到新起点那一刻的骨盆朝向坐标系里表示。
  - 参考特征：终点姿态不变；"相对起点的变化"按新起点重算；时长改成剩下的参考时长，最少取 0。
  - 标签不变，仍是那一段最后停稳的落点。
- **B（真实数据）**：C 的数据，再加上真实的进入段。

## 度量

- **主要**：在验证集和 test_iid 的真实进入段上，模型预测落点的误差中位数（cm）。
  - 只算出发前停稳的那些段：用力的那只手在命令前 0.5 s 内的速度低于 2 cm/s。
  - 给出 A/B、C/B、A/C 三个比值，区间按重置重抽样算 95 %。
  - 同时报"手停在命令处"的误差，也就是不用模型、直接执行的误差。
- **次要**：在开点和预抓取的验证段上，A 和 C 的误差。用来看中间点样本会不会伤到长伸手。

## 预测

- B 在进入段上：0.3–0.9 cm。旧模型的总体验证误差是 0.568 cm。
- C/B：1.5–4。没有进入段，相当于在数据范围外。
- A/B：1.3–2.5。
- A/C：0.6–0.95。中间点样本有一点帮助，但补不齐。
- 长伸手上 A 和 C 相差不超过 ±10 %。

## 判据

| 结果 | 结论和下一步 |
|---|---|
| A/B ≤ 1.15，并且区间上限 ≤ 1.3 | 中间点办法可行。以后换控制器时，不再专门补采短伸手，改用中间点样本；data3b 本轮照常采完，用来作对照 |
| A/B ≥ 1.3 | 中间点办法替代不了真实数据，补采是必要的。A/C < 0.9 的话，中间点样本可以作为附加数据，合并训练时另外测 |
| 两者之间 | 换 seed 1 再跑一次 A 和 B，再下结论 |
| 长伸手上 A 比 C 差 10 % 以上 | 中间点样本会伤到长伸手。不管上面哪种结论，都不能直接混进训练 |

注意这个测试用的是我们自己仿真里的 ScaleBFM，不是 LML 宿主里的三个控制器。它只回答原理上行不行。
