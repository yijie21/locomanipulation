## 模型（每个控制器都一样）

| 名字 | 训练数据 | seed | 用来回答什么 |
|---|---|---|---|
| T3 | 只用 data3（train3 已经训好，frac 1.0，seed 0），直接拿来用 | 0 | 对照 |
| M | data3 + data3b | 0、1、2 | 补采有没有用 |
| M_f0.3、M_f0.6 | M 的 30 %、60 % 子集，按重置嵌套抽 | 0 | 学习曲线 |
| D | M 的数据，再加上从训练划分切出的中间点样本 | 0、1、2 | 中间点样本合并以后还有没有用 |

## 度量

所有误差都是中位数，区间按重置重抽样，取 95 %。val 和 test_iid 都报，以 test_iid 为准。

- **data3 的 val 和 test_iid**：看合并以后，原来那块分布上的误差有没有变差。按 train3 的方式拆开报。
- **data3b 的 val 和 test_iid，按伸手种类拆开**：
  - 进入段；
  - 预抓取段；
  - 相对伸手，分 < 15 cm、15–30 cm、> 30 cm 三档；
  - 进入段里，手离抓取点 8–17 cm、手腕要转 < 20° 的那一格单独报。
- **LocoManiLab 真实局**：用 [selfmodel_lmlreal_20261125](selfmodel_lmlreal_20261125.md) 记下的伸手离线评估，第一下和第二下分开报。
- **比值**：
  - M / T3：data3b 的进入段上、data3 上、真实局第二下上各算一次；
  - D / M：看 3 个 seed 的平均，再看 seed 之间的范围；
  - 学习曲线：frac 1.0 对 0.3 的比值。
- **位置误差和姿态误差都报**，还要报"手停在命令处"时的直接执行误差。

## 假设

1. data3 里几乎没有"停稳的抬手 + 短距离 + 小转腕"这种伸手，所以 T3 在这一下上会明显变差。M 补上了这一块，误差应该回到其他伸手的水平，而且原来那块分布上的误差不会变差。
2. 在已经有真实进入段的情况下，中间点样本的帮助会小很多。relabel 测试里 A/C = 0.56，那是在完全没有进入段的前提下。

## 预测

- **data3b 的进入段**：
  - T3 的误差是它在 data3 val 上的 1.5–3.5 倍；
  - M/T3 在 0.3–0.7 之间；
  - M 在进入段上的误差，是 M 自己在 data3 val 上的 0.8–1.5 倍。
- **data3 的 val 和 test**：M/T3 在 0.85–1.02 之间。
- **真实局第二下**：M/T3 在 0.5–0.85 之间；第一下在 0.85–1.05 之间。
- **D/M**：
  - 进入段上 0.85–1.02，原来那块分布上 0.92–1.02；
  - 3 个 seed 之间的区间会把 1.0 包进去，或者只是勉强不包。
- **合并以后的学习曲线**：frac 1.0 对 0.3 的比值在 0.75–0.90，曲线还在降，但比 train3（0.70–0.75）平一些。
- **三个控制器的方向一致**。HEFT 因为跑离多、数据少，区间会更宽。

## 判据

| 结果 | 结论和下一步 |
|---|---|
| data3b 进入段上 M/T3 ≤ 0.7，且区间上限 < 0.85 | 补采有效，M 作为这个控制器的主模型 |
| data3b 进入段上 M/T3 > 0.85 | 补采没把这一下补准。先查进入段的标签和停稳；再看是不是数据量不够（学习曲线） |
| data3 上 M 比 T3 差 5 % 以上 | 合并伤到了原来的分布。查两份数据的比例，考虑重新加权（另行登记） |
| D/M ≤ 0.95，3 个 seed 都 < 1.0 | 以后的配方加入中间点样本 |
| D/M 在 0.95–1.0 之间，或者各 seed 方向不一致 | 不加中间点样本，配方保持简单 |
| D/M > 1.0 | 不加中间点样本 |
| 合并后 frac 1.0 对 0.3 仍降 10 % 以上 | 下一轮继续加采，重点放在误差最大的几格 |
| 合并后 frac 1.0 对 0.3 降不到 5 % | 这一轮停止加采 |
| 真实局第二下的误差仍 > 2 倍 val | 找出是哪些量落在范围外，针对它们补采 |

## 预测修订

### 修订 0：train3 复核以后、合并训练开始以前（2026-11-25）

原有的预测和判据不改，下面只做补充。起因是 train3 的独立复核发现：第二次伸手，也就是从上一次伸手留下的姿态出发的那一下，误差是第一次伸手的 2.4–3.3 倍。四个比值：
- ScaleBFM 0.49，SONIC 0.43，HEFT 0.60–0.63；第一次伸手只有 0.18–0.29。

第二次伸手的误差还会随上一次落空的距离变大，相关系数最高 0.30。这说明模型可能缺一个输入：发命令时，手和控制器参考之间差多少。data.py 里已经有 `REACHWM_X0_REF` 这个开关，打开后会把发命令时的参考手点，以及它和实测手点的差，一起放进 x0。"从停稳的抬手出发"正是第二次伸手这种情况；data3b 里有 3/4 的伸手属于这一类。

**补充 1：所有评估都按"第几次伸手"拆开**
- 第一次伸手：从默认站姿出发，或走完停稳后出发。
- 接着上一次动作的伸手：data3 的第二次伸手，以及 data3b 里除第一下以外的各下。
- 先走路和原地的比较，只在第一次伸手上做。train3 里把两次伸手混在一起算，差别被冲淡了。
- 每一格除了中位数，也报 p90。
- 另外报 edge 组（z < 0.08 m、过中线 0.5 m 以上），这一组不参与训练，只用来看外推表现。

**补充 2：新增模型 MX**

MX 和 M 用同一份数据、同一组 seed（0、1、2），唯一的区别是另加 `REACHWM_X0_REF=1`。

开训之前先核对 data3 和 data3b 的 C 行里存的是不是逐行的参考手点，也就是 data.py 的 X0_REF 要读的那个量。如果不是，或者算不出来，MX 就不做，写明原因。

**补充的预测**

| 项 | 预测 |
|---|---|
| T3 在"接着上一次动作"这一格上的误差 | 是它第一次伸手误差的 2.2–3.5 倍（train3 里是 2.4–3.3 倍） |
| M/T3，"接着上一次动作"那一格 | 0.6–0.85 |
| M/T3，第一次伸手 | 0.9–1.02 |
| MX/M，"接着上一次动作"那一格 | 0.75–0.95 |
| MX/M，第一次伸手 | 0.95–1.03 |

**补充的判据**

| 结果 | 结论和下一步 |
|---|---|
| "接着上一次动作"那一格 MX/M ≤ 0.9，3 个 seed 都 < 1.0，且第一次伸手 MX/M ≤ 1.03 | 以后的配方打开 `REACHWM_X0_REF`。真实局和 SIMPLE 的部署代码也要能拿到参考手点 |
| MX/M 在 0.9–1.0 之间，或 seed 之间方向不一致 | 不打开 |
| M 在"接着上一次动作"那一格上的比值仍 > 0.5 | 那个控制器的这类伸手还不能说已经学出来。下一步先补输入，或者改特征，再考虑加采 |
