## 假设

用同一套采法采来的数据，三个控制器都能学出自身模型。条件是覆盖要全：原地和走完停稳都有，左右手都有，高度从 0.05 m 到 1.5 m，手腕朝向包括滚转和 ±90° 的偏转。在每一种拆分下，误差都应该接近总体，不能有某一块明显学不好。

## 度量

所有误差都是中位数，在验证集上算；另外报 test_iid 的数。只算没摔倒、没跑离、停稳了的段。

- **终点位置误差（cm）**：分两组报，模型预测的落点，和"手停在命令处"这个不用模型的假设。后者就是直接执行的误差。比值等于模型误差除以直接执行误差。
- **终点姿态误差（度）**：模型预测的姿态和实际姿态之间的测地角。同样报不用模型时的值。
- **拆分**：
  - 原地 / 先走路；
  - 右手 / 左手；
  - 高度段：z < 0.3、0.3–0.6、0.6–0.9、0.9–1.2、≥ 1.2 m；
  - 朝向段：|偏转| ≤ 60° 对 > 60°，|滚转| ≤ 40° 对 > 40°，俯仰 < 0° 对 ≥ 0°；
  - 站 / 蹲。
- **学习曲线**：三个 frac 的验证误差。
- **区间**：每一格都报段数，并按重置重抽样给出 95 % 区间。

## 预测（训练之前写，没看过正式数据）

数据条目里已有的这里不变：
- 100 % 数据时的验证误差：ScaleBFM 1.6–2.6 cm，HEFT 3–5 cm，SONIC 3–7 cm；
- 先走路的误差是原地的 1.0–1.5 倍。

新增：
- **模型对直接执行的比值**：ScaleBFM 0.15–0.28，HEFT 0.25–0.45，SONIC 0.25–0.5。冒烟里直接执行的误差是 8.5、10.6、13.1 cm。
- **左右手**：同一个控制器左右手相差在 ±20 % 以内。
- **高度**：最低段（z < 0.3）和最高段（≥ 1.2）的误差是总体的 1.1–1.8 倍。
- **新补的朝向**：|偏转| > 60° 和 |滚转| > 40° 两格的误差是总体的 1.0–1.6 倍。
- **姿态误差**：模型的姿态误差比不用模型时低 30–70 %，三个控制器都一样。我对姿态误差没有先验，区间放得宽。
- **学习曲线，从 frac 0.3 到 1.0 的误差比**：ScaleBFM 0.78–0.92，HEFT 0.82–0.97，SONIC 0.82–0.97。
- **HEFT 的数据偏短伸手**：伸手时长 > 2.5 s 的那一格段数很少，误差是总体的 1.2–2.5 倍。

## 判据

| 结果 | 下一步 |
|---|---|
| 某个控制器模型对直接执行的比值 > 0.5 | 先查标签：停稳窗口和延迟有没有对齐，跑离截断对不对。查清以前不加数据 |
| 先走路 > 1.5 倍原地 | 加采先走路的局 |
| 先走路 ≤ 1.2 倍原地 | 以后可以少采走路 |
| 从 frac 0.3 到 1.0 误差还降 10 % 以上 | 这个控制器加采，直到降幅小于 5 % |
| 某个高度段或朝向段 > 2 倍总体 | 在那一段加密采样 |
| 左右手相差 > 30 % | 查左手的镜像和采样有没有问题 |
| 姿态误差模型不比不用模型低 | 姿态这一项不进 claim，先查姿态标签 |
