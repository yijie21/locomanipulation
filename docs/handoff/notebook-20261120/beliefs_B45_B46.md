# beliefs.md 摘录：B45、B46（2026-11-20，原文照抄自 Mac 上的 ~/research-notebook/beliefs.md）

- [B45] 头部相机那一眼的点云能当避障地图用。设定：SIMPLE TabletopGrasp，ScaleBFM，cuRobo 只放开右臂。
  - **感知：**
    - 用机器人自己的模型渲染出哪些像素是自己的身体，再把它们去掉，不再用"前方 20 cm 以内都算自己"。
    - 桌沿误差中位数 0.20 cm（老办法 7.6 cm）。
    - 亮面或玻璃桌的 4/30 局，桌沿处深度往下塌，误差 8–19 cm，机器人自己察觉不到。
  - **规划：**cuRobo 在 27/29 局规划出路线，在仿真几何上离桌子 ≥ 2.2 cm。
  - **评测：**卡住 18/19 → 1/1，45 s 成功 direct 2 → 12、model 3 → 17。
  - **代价：**
    - 有路线的 27/28 局里，手越过桌沿时仍碰桌约 1 s；
    - 路线长一倍，成功时刻跨过 SIMPLE 的 16 s 官方时限，官方成功率 direct 2 → 5、model 3 → 2。
  - **盒子任务：**锁腰只动右臂的规划器在 83/90 局够不到预抓取位姿，这组没检验到。
  - **model 和 direct：**有路线后 model 胜 direct 不显著（45 s 6:1，p = 0.125；16 s 0:3）。
  — 证据：curobo_avoid_20261120（含独立复核）— 置信度：中（卡住消失）；低（model 胜、绕行是原因）。一次运行，种子 0，每种方法 29 局。— 2026-11-20
  → curobo_attrib_20261120 补充（2026-11-20）：卡住消失靠的是"先把手抬到预抓取高度"，不是感知规划本身；见 B46。
- [B46] SIMPLE TabletopGrasp 的"手卡在桌下"，原因是手从桌板下面往前伸、还没抬过桌面高度。
  - **能解决的：**
    - 不用感知的"先竖直抬到预抓取高度再过去"：卡住 0 / 16 个卡住局，0 / 26 全部局；
    - 先撤后抬模板 0 / 84；cuRobo 路线 0 / 84。
  - **解决不了的：**
    - 只后撤不抬：11 / 16；
    - 同段数、同时长的直线：49 / 84，和直线相同；
    - 直线位置配 cuRobo 姿态：41 / 84。
  - **这个基准说明不了感知规划的必要性：**28 局同一张桌子，障碍永远在目标下方。要证明感知规划有用，得用障碍物随机的场景。
  - 模板的 16 s 官方成功率高，主要是路程短约 1 s，不是路线形状更好。
  — 证据：curobo_attrib_20261120（含独立复核和它的 60 局追加实验）— 置信度：高（位置路径是原因、抬高是关键）；中（只限此基准）。一次运行，direct，约 28 个独立局。— 2026-11-20
