# Planner 手臂参考的实际响应

2026-09-06 的固定参考实验确认：当前 Planner→SONIC 链路不是能精确交付任意 IK 关节解的位置控制器。相同历史失败参考在空地保持 8 s 后，站立/下蹲的手掌朝向误差约 24° / 44°，位置误差约 2.5 / 3.3 cm。实测关节 FK 与手掌真值一致，因此不能把这次偏差解释成 FK 坐标约定错误。

下蹲 height 指令不固定实际身体几何：手臂参考改变后，骨盆也改变。当前测试 height=0.64 时，骨盆最终约 0.693 m。位置与朝向需以当前身体完整姿态测量，路径的身体静止假设必须持续检查。

`tools/diag_arm_response.py` 提供空地、无 pin、无 VLA 的保持/右腕扰动测试；每次使用 fresh deploy，同一 reference JSON，`--posture standing|crouched`，`--hold-only` 保持 8 s。`tools/analyze_arm_response.py` 汇总尾部实测误差、局部响应和身体漂移；`--require-rate` 检查发送中位周期不超过 30 ms，`--require-pose` 检查尾部位姿满足现有运输阈值，失败非零退出。

第一版探针两次阻塞观测把发送拖慢到约 24 Hz。现已改为一次阻塞观测，明确记录发送前状态和命令各自时钟；原速复核约 49 Hz，仍出现稳态偏差。旧版扰动增益包含发送速度偏差、局部非线性和历史状态影响，不能直接用于生产逆补偿。

下一项验收应是受约束的末端位姿闭环与可跟踪姿态选择：固定目标、测量实际误差、逐步更新参考；持续检查碰撞、身体漂移和关节饱和。空地闭环先通过原有到位阈值，再验证桌前运输与抓取。遇到不可跟踪的姿态应改变站位或 IK 分支，不能以无限等待、扩大补偿上限或跳过到位判据构造成功样本。

详细命令、六次测量、响应图与限制见 `outputs/diag/arm_response_20260906/REPORT.md`。这不是 VLA 原始停滞的完整因果诊断；尚未区分 encoder、decoder 和动力学各自的贡献。

## 末端反馈诊断（后续批次）

新增 `pose_feedback.PoseFeedback` 提出受速度、关节范围和 0.35 rad 总改变量限制的主动臂参考；`tools/diagnostic_pose_servo.py` 根据实际世界系手掌位姿闭环，发送前保留碰撞筛查，并沿用 4 cm 身体漂移约束。连续 1 s 满足位置 <4.5 cm、朝向 <0.25 rad 才算交付。

空地同类失败参考的两次低速闭环通过该门槛；较高速一条因身体漂移退出。这是局部可行性证据，不是任意 IK 解可跟踪的证明。桌前入口为 `diag_crouched_handover.py --transport-strategy planned --transport-pose-feedback`，仍只用于诊断。

桌前发现 `PlannerArm._push` 中的另一只手避让会再次阻塞读取观测。新增可选 `observed` 参数，供新闭环把已验证的新鲜状态交给避让检查；旧调用默认行为不变。没有把旧采集循环全面改为单次观测，也不能以空地周期推断桌前周期。

实验结果、失败分类和时序复测见 `outputs/diag/pose_feedback_20260906/REPORT.md`。

最终桌前复测 2/3 抓起保持成功，1 条在规划前因站位几何拒绝；两条反馈周期约 20.6 / 20.8 ms。样本少且接管状态未严格配对，不能当作 VLA 成功率提升。默认采集尚未切换。
