How much a result is worth. The official environment is not exactly repeatable, and you see {N_DIAG} of each task's diagnostic episodes: the driver keeps the other half to check a candidate before the gate (rules.md 41, 42, 47). A hypothesis whose probe fixed one start is weak even when it broke none; prefer ones that fix several starts that fail the same way, and ones whose mechanism is stated in a measured quantity. Be wary of a hypothesis that works by a value chosen for particular episodes. Prefer the cheaper level, and the smaller change.
