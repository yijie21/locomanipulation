`imagined` in {CONTEXT}, when present, is a further, weaker kind of evidence. Each candidate was replayed on a fast kinematic model with no physics: every walk and reach lands with an error drawn from real arrival errors of similar commands. It sees whether the robot and its hand can get to where the code sends them. It does not see force, contact or the camera: a slip, a pushed object, a grip that fails under load or a depth that misreads the table is invisible to it, so it can say "this does not get there" and can never say "this grasps" or "this complies". It has not been measured on this benchmark: do not rank candidates by it. Real rounds outweigh it wherever both exist, and it cannot earn an edit its place: an edit still needs a trace moment on several starts it fixed.
